# Bahn Ops Controller

Prompt Operations Hackathon, 24-25 Oct 2026.
Bahn challenge: an agentic operations controller for car transport.

Three entry points. Each runs on its own; none requires another.

## 1. Control room (Node, no dependencies)

 node board/server.cjs

Serves http://127.0.0.1:4317 — only the orders that need a person, each with
the reason it surfaced, the agent proposal, the rationale, and the ids the
proposal relied on.

Reads bahn_ops/ours.jsonl when that file exists, and falls back to the
shipped board/dataset/data/agent_proposals.jsonl when it does not.

## 2. Agent (Python 3, stdlib only)

 python3 bahn_ops/agent.py

Reads the open alerts from board/dataset/data, writes one proposal per alert
to bahn_ops/ours.jsonl. Safe to rerun: alerts already present in that file
are skipped.

No model key means the deterministic path runs and each row records the
reason in model_error. A key means the model writes the proposal and each
row records source as model.

## 3. Ops API (FastAPI)

 python3 -m venv .venv
 .venv/bin/python -m pip install -r requirements.txt
 .venv/bin/python -m uvicorn app.main:app --port 8000

Health: http://127.0.0.1:8000/health

Windows with Git Bash:

 python -m venv .venv
 .venv/Scripts/python.exe -m pip install -r requirements.txt
 .venv/Scripts/python.exe -m uvicorn app.main:app --port 8000

## Config

Copy .env.example to .env and fill locally. Never commit .env.

 BAHN_MODEL_API_KEY=
 BAHN_MODEL_BASE_URL=
 BAHN_MODEL_NAME=

Blank settings run the deterministic path.

## What is in here

- board/server.cjs — the control room.
- board/dataset/ — Bahn's synthetic dataset, 50 jsonl files.
- bahn_ops/agent.py — the proposal loop.
- bahn_ops/ours.jsonl — generated by the agent. Not tracked.
- bahn_ops/controller.py — first build, deterministic order parsing, pricing,
 driver assignment. Kept as history, not the submission.
- app/main.py — FastAPI shell.
- PROCESS.md — how this was built with AI, written during the build.
